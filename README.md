# dotfiles

Personal dotfiles, for my own use only.

Forked from [crafts69guy/.dotfiles](https://github.com/crafts69guy/.dotfiles) — all credit for the original setup goes to them.

## Setup

```bash
brew install stow git fish tmux neovim fd ripgrep bat eza fzf

git clone https://github.com/howsillyistoosilly/ghostty-dotfiles.git ~/.dotfiles
cd ~/.dotfiles
./stow_setup.sh
```

Use at your own risk!
